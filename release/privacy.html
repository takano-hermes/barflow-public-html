プライバシーポリシー

最終更新日：2026年6月15日

本プライバシーポリシー（以下「本ポリシー」）は、BarFlow（以下「開発者」）が提供するGoogleスプレッドシート用アドオン「BarFlow」（以下「本アドオン」）における、ユーザーデータの取扱いについて説明します。

1. 収集するデータ

本アドオンが収集するデータは以下のものに限定されます。

  • バーコード生成用データ：ユーザーが明示的に選択・設定したスプレッドシート上のセル値（バーコード化対象のテキスト・数値）のみを、アドオン実行時に一時的に読み取ります。
  • 利用状況データ：本アドオンの機能改善のため、匿名化された利用統計（例：生成されたバーコードの種類と数）を収集することがあります。このデータには個人を特定する情報は含まれません。

本アドオンは、ユーザーのスプレッドシート上のすべてのデータを無差別に収集・保存することはありません。バーコード生成のために必要最小限のデータのみにアクセスします。

2. データの処理方法

バーコードの生成処理は、以下の通りクラウド基盤上で行われます。

  • ユーザーがスプレッドシート上でバーコード生成対象のセルを選択します。
  • 選択されたバーコード値とタイプが、Google Apps Script から Cloud Run（cr.barflow.g.jinxiao.jp）に IdToken 認証付きで POST 送信されます。
  • Cloud Run（Node.js + bwip-js）にて SVG と PNG の両方のバーコード画像が生成されます。
  • 生成された画像は Google Cloud Storage（barflow-generate バケット）に保存されます。
  • 画像のメタデータは Firestore（barflow-barcodes コレクション）に保存されます。
  • 画像 URL が GAS に返却され、スプレッドシート上の指定セルに画像として挿入されます。

これらの処理はすべてユーザーのブラウザ上ではなく、Google Cloud 上のサーバーサイドで実行されます。

3. データの保存と保持

  • 生成されたバーコード画像は Google Cloud Storage（barflow-generate バケット）に保存されます。画像は生成から一定期間経過後に自動的に削除されます。
  • バーコードのメタデータ（生成日時、バーコードタイプ、対応する画像パス等）は Firestore（barflow-barcodes コレクション）に保存されます。
  • バーコード生成のために読み取られた元データそのもの（スプレッドシート上のセル値）は、Cloud Run および GCS・Firestore には保存されません。生成処理完了後にサーバーサイドのメモリ上から破棄されます。
  • すべてのユーザーデータはユーザーの Google スプレッドシート内に保持され、Google のサーバー上で管理されます。データの保持期間はユーザーがスプレッドシートを削除しない限り継続します。

4. サードパーティサービス

本アドオンは以下のサードパーティサービスを利用しています。

  • Google Cloud Run：バーコード画像の生成処理（Node.js + bwip-js）を実行するサーバーレスコンテナです。バーコード値とタイプが処理のために送信されます。詳細は Google Cloud Run のデータ処理 をご確認ください。
  • Google Cloud Storage：生成されたバーコード画像の保存に使用します（barflow-generate バケット）。詳細は Google Cloud のプライバシーポリシー をご確認ください。
  • Firestore：バーコードのメタデータ（生成日時、タイプ、画像パス等）の保存に使用します（barflow-barcodes コレクション）。詳細は Google Cloud のプライバシーポリシー をご確認ください。
  • Stripe：有料サブスクリプションの決済処理に使用します。Stripeが収集する支払情報（クレジットカード情報等）はStripeのプライバシーポリシーに従って管理され、開発者は完全なクレジットカード情報にアクセスすることはありません。詳細は Stripeのプライバシーポリシー をご確認ください。
  • Google Sheets API：スプレッドシート上のデータの読み取り・書き込みに使用します。データの取扱いは Googleのプライバシーポリシー に従います。

5. データの共有

開発者は、以下の場合を除き、ユーザーデータを第三者と共有することはありません。

  • ユーザーの明示的な同意がある場合
  • 法令に基づき開示が要求された場合
  • サービスの提供に必要な範囲でサードパーティサービス（Stripe等）と連携する場合

6. GDPR（一般データ保護規則）への対応

欧州経済領域（EEA）にお住まいのユーザー様に対して、以下の権利を尊重します。

  • アクセス権：ユーザーはご自身のデータへのアクセスを要求する権利を有します。
  • 訂正権：不正確なデータの訂正を要求する権利を有します。
  • 削除権（忘れられる権利）：データの削除を要求する権利を有します。本アドオンの場合、ユーザーがご自身のスプレッドシートを削除することでデータを完全に削除できます。
  • 処理制限権：特定の状況下でデータ処理の制限を要求する権利を有します。
  • データポータビリティ権：データの移転を要求する権利を有します。

これらの権利を行使されたい場合は、下記のお問い合わせ先までご連絡ください。GDPRに関するお問い合わせには30日以内に対応いたします。

7. データのセキュリティ

開発者は、ユーザーデータの保護に努めています。本アドオンはGoogle Apps Scriptの標準セキュリティモデルに従い、必要なスコープ（権限）のみを要求します。本アドオンが要求するOAuthスコープは以下のとおりです。

  • spreadsheets.currentonly — 現在のスプレッドシートへの読み取り・書き込み（バーコードの生成と挿入のため）
  • script.container.ui — アドオンサイドバーおよびダイアログの表示（ユーザーインターフェース提供のため）
  • script.scriptapp — スクリプト実行制御およびトリガー管理のため
  • userinfo.email — ユーザーのメールアドレス取得（サブスクリプション管理・問い合わせ対応のため）
  • script.send_mail — サポート・通知メールの送信のため
  • script.external_request — Cloud Run への HTTP リクエスト（バーコード生成API呼び出し）のため

Cloud Run へのリクエストは IdToken 認証 により保護されており、正規のアドオンからのみアクセス可能です。各 Google Cloud サービス間の通信は Google のインフラストラクチャ内で暗号化されています。
